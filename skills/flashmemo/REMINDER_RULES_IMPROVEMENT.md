# FlashMemo 提醒设置规则改进

## 🎯 问题

**之前的行为** ❌：
```
用户："记得提醒我给妈妈买生日礼物"
OpenClaw: "✅ 已设置提醒"  ← 错！什么时候提醒？
```

**问题**：用户没有说具体时间，但系统自动设置了提醒，导致：
- 提醒时间不明确
- 用户可能错过重要事项
- 体验不好

---

## ✅ 改进规则

### 核心原则

**没有明确时间 = 不设置提醒，只存储备忘 + 追问**

---

### 处理流程

```
用户提到待办/提醒
    ↓
检查是否有明确时间？
    ↓
    ├─ ✅ 有明确时间 → 存储 + 设置提醒
    │
    └─ ❌ 无时间/模糊 → 存储 + 追问确认
```

---

### 时间明确性判断

| 用户表述 | 时间明确？ | 操作 |
|---------|-----------|------|
| "明天下午 3 点" | ✅ 明确 | 存储 + 设置提醒 |
| "今天下午" | ✅ 明确 | 存储 + 设置提醒 |
| "下周一" | ✅ 明确 | 存储 + 设置提醒 |
| "3 月 15 日" | ✅ 明确 | 存储 + 设置提醒 |
| "下周" | ❌ 模糊 | 存储 + 追问"下周几？" |
| "下个月" | ❌ 模糊 | 存储 + 追问"几号？" |
| "记得提醒我" | ❌ 无时间 | 存储 + 追问"什么时候？" |
| "有空的时候" | ❌ 无时间 | 仅存储（普通） |

---

### 追问话术示例

#### 场景 1：用户完全没说时间

```
用户："记得提醒我给妈妈买生日礼物"

✅ 正确回复：
"好的，已记录待办：给妈妈买生日礼物。
需要什么时候提醒你？比如：
- 明天？
- 下周一？
- 还是具体某个日期？"
```

#### 场景 2：用户说了模糊时间

```
用户："下周提醒我交报告"

✅ 正确回复：
"好的，已记录待办：交报告。
具体是下周几呢？
- 下周一（3 月 17 日）？
- 下周三（3 月 19 日）？
- 还是下周五（3 月 21 日）？"
```

#### 场景 3：用户说了明确时间

```
用户："明天下午 3 点提醒我开会"

✅ 正确回复：
"✅ 已设置提醒：明天（3 月 11 日）下午 3 点 开会"
```

#### 场景 4：用户说"有空的时候"

```
用户："有空的时候提醒我学游泳"

✅ 正确回复：
"好的，已记录：学游泳。
这是一个普通待办，没有设置具体时间。
等你有空的时候查看备忘列表就能看到。
需要我设置一个具体提醒时间吗？"
```

---

### 紧急程度判断

| 关键词 | 紧急程度 | 操作 |
|--------|---------|------|
| 今天、明天、截止、立即 | 🔴 紧急 | 存储 + 如没时间则追问 |
| 记得、别忘了、必须、关键 | 🟡 重要 | 存储 + 如没时间则追问 |
| 有空、计划、打算 | ⚪ 普通 | 仅存储，不需要追问 |

## 🎯 关键要点

### ✅ 正确做法

1. **检查时间明确性**
2. **明确时间 → 直接设置**
3. **模糊时间 → 追问确认**
4. **无时间 → 追问或仅存储**

### ❌ 错误做法

1. **自动假设时间** ❌
2. **不追问就设置** ❌
3. **忽略时间模糊性** ❌
