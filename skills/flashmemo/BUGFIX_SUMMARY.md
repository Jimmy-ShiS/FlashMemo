- 优雅降级到规则分类

### 2. 账目汇总为 0
**问题**：`calculate_account_summary` 函数只能处理标准格式
- ✅ 支持：`收入 - 兼职稿费 -500.00`
- ❌ 不支持：`今天收到兼职稿费 500 元`

**修复**：
```python
# 改进版支持多种格式
# 1. 标准格式：收入 - 类别 -500.00
# 2. 自然语言：今天收到兼职稿费 500 元
# 3. 混合格式：2026-03-10.13:17:49: 今天收到兼职稿费 500 元

def calculate_account_summary(records):
    for record in records:
        # 提取金额（多种格式）
        amount_match = re.search(r'(\d+\.?\d*)\s*(?:元 | 块)?$', record)
        
        # 判断收入/支出
        is_income = any(kw in record for kw in ['收入', '收到', '入账', '工资', '稿费'])
        is_expense = any(kw in record for kw in ['开支', '支出', '花了', '消费'])
```

---

### 3. 账目明细提取不完整
**问题**：`_extract_account_items` 只能提取标准格式

**修复**：新增 5 种提取模式
```python
# 模式 1：开支 - 类别 - 金额
# 模式 2：花了 X 元买 Y
# 模式 3：收到 X 元
# 模式 4：X 元买 YY / X 元的 YY
# 模式 5：金额 + 元/块（简单 fallback）
```
