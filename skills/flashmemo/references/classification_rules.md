# FlashMemo 分类规则详解

## 分类优先级

当一条内容可能属于多个分类时，按以下优先级处理：

1. **账目记录** (最高优先级) - 涉及金钱的交易
2. **重要备忘** - 包含时间敏感或任务型关键词
3. **工作记录** - 明确的工作相关内容
4. **生活记录** (默认分类) - 其他所有内容

---

## 账目记录关键词

### 金额标识
- `元`、`块`、`¥`、`$`、`USD`、`RMB`
- 数字模式：`\d+\.?\d*` (如 20、35.5、100.00)

### 交易动词
**支出类**：
- 开支、支出、花费、花了、消费、付款、购买、买了、付了
- 转账给、红包发出、打赏、充值

**收入类**：
- 收入、收到、入账、工资、奖金、红包收到、退款、报销

### 常见消费类别
- 餐饮：午餐、晚餐、早餐、咖啡、奶茶、外卖、聚餐
- 交通：地铁、公交、打车、加油、停车费
- 购物：超市、衣服、电子产品、日用品
- 娱乐：电影、KTV、游戏、会员
- 居住：房租、水电费、物业费
- 其他：医疗、教育、人情往来

## 紧急程度判断规则

### 紧急 (🔴)
**触发条件**：包含以下任一关键词
- 立即、马上、快点、 ASAP
- 今天、明天、后天
- 截止、deadline、最后期限
- 紧急、急用、火烧眉毛

**示例**：
- "明天下午 3 点前提交项目报告" → 紧急
- "今天要记得缴纳水电费" → 紧急
- "立即给客户回电话" → 紧急

### 重要 (🟡)
**触发条件**：包含以下任一关键词
- 记得、别忘了、记住、千万
- 必须、一定要、一定、务必
- 重要、关键、主要、核心

**示例**：
- "记得给妈妈买生日礼物" → 重要
- "必须完成季度总结报告" → 重要
- "别忘了下周的体检预约" → 重要

### 普通 (⚪)
**触发条件**：无上述关键词的常规备忘

**示例**：
- "周末整理衣柜" → 普通
- "有空去看看新出的电影" → 普通
- "计划下个月学游泳" → 普通

## 混合内容处理

当一条消息包含多种类型内容时，**拆分记录**：

**示例 1**：
```
用户：中午吃了碗拉面 20 块，下午要记得给客户回电话

处理：
1. account/2024/03/2024-03-10.md: 开支 - 午餐 (拉面)-20.00
2. ImportantMemo.md: 代办 - 重要 - 下午给客户回电话
```

**示例 2**：
```
用户：今天收到工资 8000 元，晚上要和同事聚餐

处理：
1. account/2024/03/2024-03-10.md: 收入 - 工资 -8000.00
2. life/2024/03/2024-03-10.md: 晚上要和同事聚餐
```

**示例 3**：
```
用户：上午开会讨论 Q3 计划，花了 35 元买咖啡，明天截止提交报告

处理：
1. work/2024/03/2024-03-10.md: 上午开会讨论 Q3 计划
2. account/2024/03/2024-03-10.md: 开支 - 咖啡 -35.00
3. ImportantMemo.md: 代办 - 紧急 - 明天截止提交报告
```

## 特殊场景处理

### 模糊金额
- "花了几十块" → 不记录为账目，归为生活记录
- "花了大概 100 左右" → 可记录为 `开支 - 消费 -100.00`，标注为估算

### 多币种
- 统一转换为人民币记录，或保留原币种标注
- 示例：`开支 - 购物-$50.00 (约¥360)`

### 转账/AA
- "转给小王 200 元" → `开支 - 转账 -200.00`
- "小王转我 100 元" → `收入 - 转账 -100.00`
- "AA 聚餐每人 150" → `开支 - 聚餐 -150.00`

### 退款/报销
- "收到退款 50 元" → `收入 - 退款 -50.00`
- "报销了 200 元交通费" → `收入 - 报销 -200.00`
