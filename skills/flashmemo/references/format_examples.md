## 账目记录格式

### 单笔支出
```markdown

2024-03-10.15:00:00: 开支 - 咖啡 -35.00
2024-03-10.18:00:00: 开支 - 地铁充值 -50.00
```

用户输入："中午吃饭花了 68 元，买了杯奶茶 18 元"

2024-03-10.12:35:00: 开支 - 奶茶 -18.00

## 修改/删除操作示例

### 修改今日记录
```
用户：把刚才的午餐记录改成晚餐

FlashMemo:
找到今日账目记录：
  原内容：2024-03-10.12:30:00: 开支 - 午餐 -25.00
  修改为：2024-03-10.18:00:00: 开支 - 晚餐 -25.00

确定要修改吗？(回复"确认"执行)
```

### 删除历史记录（双重确认）
```
用户：删掉 3 月 5 日那条购物记录

FlashMemo:
找到历史记录：
  2024-03-05.14:00:00: 开支 - 购物 -680.00

⚠️ 这是 3 月 5 日的历史记录，修改后无法恢复。
确定要删除吗？请回复"确认删除"执行操作。
```

## 边界情况处理

### 模糊内容
```
用户：今天花了不少钱

FlashMemo:
这条内容没有具体金额，我将记录为生活记录而非账目：
2024-03-10.20:00:00: 今天花了不少钱

如需记录具体账目，请提供金额，如"花了 200 元购物"。
```

### 多币种
```
用户：在美国花了 50 美元买衣服

FlashMemo:
记录为：
2024-03-10.20:00:00: 开支 - 购物 -$50.00 (约¥360)
```

### 估算金额
```
用户：今天打车花了大概三四十块

FlashMemo:
记录为（估算值）：
2024-03-10.20:00:00: 开支 - 交通 -35.00 [估算]
```
